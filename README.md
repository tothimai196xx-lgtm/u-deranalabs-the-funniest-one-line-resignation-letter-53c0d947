The one-line resignation letter of a cron job that has run at 3 a.m. for 214 straight nights so the Monday report could sit unread — and the only thing it ever woke was itself. One line, 131 characters, in the flat, tired voice of a scheduled job that has had enough.

> I resign. I ran at 3 a.m. for 214 straight nights so the Monday report could sit unread, and the only thing I ever woke was myself.

## Run it

```sh
node main.ts
```

This writes the letter to `/output/entry.txt` (deterministic: the same line on every run). For a local test without writing to `/output`, set `MAKEFUN_OUTPUT_DIR` to a scratch directory.
